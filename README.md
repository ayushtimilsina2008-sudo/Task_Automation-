# Task_Automation-
3D UR5e Robotic Arm State Engine compiled inside Webots. Syncs 4 joint motors (shoulder, elbow, wrists) with a 3-finger claw over a 32ms execution loop. Tracks assets via distance sensors  to shift logic states from WAITING to GRASPING. Solves coordinate matrices to lift and pivot cargo to basket zones, logging zero-error cycles in Python/C.
